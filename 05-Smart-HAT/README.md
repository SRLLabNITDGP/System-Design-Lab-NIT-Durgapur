# Smart HAT

Head-worn sensing and interaction platform for motion, gesture and assistive human-computer interaction experiments.

## Versions

- [V1](V1/) — ESP32-S3 + BNO085 head-motion BLE mouse platform with click, drag and scroll interaction
- [V2](V2/) — revised design iteration

## V1 highlights

- Quaternion-based head orientation tracking
- BLE HID mouse control
- Cursor movement from head motion
- Left/right click, double click, drag and scroll modes
- EMA filtering and nonlinear cursor gain
- State-driven interaction arbitration
- Desktop recording and visualisation workflow
- Multi-participant gesture dataset

Hardware, firmware, datasets, analysis and documentation are maintained inside the relevant version folder.
