# System Design Lab — NIT Durgapur

Repository and GitHub Pages website for the **System Design Lab, National Institute of Technology Durgapur**.

## Research Areas
- Wearable and Human-Centred Systems
- Embedded System Design
- Edge AI and TinyML
- IoT and Connected Devices
- mmWave and Advanced Sensing
- Experimental System Validation

## Experiments
1. Smart Ring — V1, V2
2. Smart Watch — V1, V2
3. Smart Band — V1
4. Smart Toy — V1
5. Smart HAT — V1, V2
6. ESP32-P4 + mmWave — V1
7. EMD — V1

## Website
This repository contains a responsive 3D animated static website designed for GitHub Pages.

## Structure
Each experiment keeps its own README and version folders. Common documentation and reusable material are placed under `Common-Resources/`.
