# GitHub Pages

This repository contains the System Design Lab website in the repository root.

To publish it with GitHub Pages:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/ (root)**.
4. Save the setting.

Expected site URL:

`https://srllabnitdgp.github.io/System-Design-Lab-NIT-Durgapur/`
