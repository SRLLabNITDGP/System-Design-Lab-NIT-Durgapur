# Contributing

Thank you for contributing to the System Design Lab repository.

## Experiment organisation

Keep each project inside its numbered experiment folder. Use the version folders (`V1`, `V2`, etc.) to preserve design history rather than replacing older experimental work.

A version folder may contain:

- `Hardware/`
- `Firmware/`
- `Dataset/`
- `Analysis/`
- `Results/`
- `Documentation/`

## Commit guidance

Use short, descriptive commit messages. Keep code, data notes and documentation connected to the experiment they belong to.

Do not add private credentials, API keys, personal data or unpublished sensitive datasets to the public repository.
